## 🚀 部署（Netlify）

纯静态，零构建。两种方式任选：

**方式一：Git 自动同步（推荐）**
1. [app.netlify.com](https://app.netlify.com) → Add new site → Import an existing project
2. 选择 GitHub 仓库 `personalShowWebsite_Yusloaner0199`
3. Branch: `main`，Build command 与 Publish directory 均留空
4. Deploy —— 之后每次 `git push` 自动重新部署

**方式二：手动拖拽**
直接把整个文件夹拖进 Netlify 部署页即可。
